## Демо проект онлайн-магазина


Проект представляет из себя backend для интернет-магазина, позволяющий пользователям просматривать товары, управлять корзиной и оформлять заказы.

---

## 🚀 Функциональность

- **Управление пользователями**
    - Регистрация нового пользователя
    - Аутентификация и авторизация (JWT)
    - Профиль пользователя

- **Каталог товаров**
    - Просмотр списка всех товаров
    - Просмотр детальной информации о товаре

- **Корзина покупок**
    - Добавление товаров в корзину
    - Просмотр содержимого корзины
    - Изменение количества товаров
    - Удаление товаров из корзины

- **Оформление заказа**
    - Создание заказа из текущей корзины
    - Просмотр истории заказов
    - Разные статусы заказа

---

## 🛠 Технологии и зависимости

*Backend:*
- **Java 17**
- **Spring Boot 3.x**
- **Spring Security** (для аутентификации и авторизации)
- **Spring Data JPA** (для работы с базой данных)
- **Hibernate** (как JPA провайдер)
- **Maven** (как система сборки)
- **База данных:** MySQL (для разработки)
- **JWT** (для создания и верификации токенов)
- **Lombok** (для сокращения boilerplate кода)
- **MapStruct** (для маппинга DTO)
- **Docker** (для контейнеризации)
